## Features (Part 3)

- Accordion on the About section (keyboard accessible, `aria-expanded`).
- Projects rendered from a JavaScript array with search, skill filter and sort.
- Gallery with a lightbox built on the native `<dialog>` element (Esc, arrow keys, focus returns).
- Interactive Leaflet map on the contact page.
- CSS transitions and keyframe animations, disabled by `prefers-reduced-motion`.
- Enquiry form: HTML5 plus JavaScript validation, pricing fetched from `data/pricing.json`, estimate shown on the page.
- Contact form: validated, then compiled into a `mailto:` email to the recipient set in `script.js`.
- SEO: unique titles and meta descriptions, one `<h1>` per page, descriptive image names and alt text, internal links, `robots.txt`, `sitemap.xml`.
- Security: user input is displayed with `textContent`, external links use `rel="noopener noreferrer"`.
